# نظام إجازات المنسوبين

تطبيق ويب من صفحة واحدة (Single-file HTML App) لإدارة إجازات منسوبي مركز تدريب الدفاع المدني بمنطقة المدينة المنورة — لا يحتاج إلى خادم أو قاعدة بيانات، ويعمل بالكامل من داخل المتصفح.

## المزايا

- تسجيل دخول باسم مستخدم وكلمة مرور.
- أيقونات لكل شعبة/قسم: شعبة التعليم، شعبة التدريب، شعبة المساندة الإدارية، شعبة أجنحة التدريب، قسم الجودة التعليمية، المكتب.
- داخل كل شعبة: اختيار المنسوب ← اختيار نوع الإجازة (عرضية 1-10 أيام / اعتيادية 1-45 يوم) ← تاريخ البدء من تقويم ← حساب تاريخ الانتهاء تلقائيًا ← حفظ.
- نسبة المتمتعين بالإجازة ونسبة المتواجدين تُحسب لحظيًا بحسب تاريخ اليوم.
- جدول الإجازات السابقة لكل شعبة مع تصفية حسب المنسوب ونوع الإجازة، وإمكانية الحذف.
- صفحة "الإجازات العامة" تجمع كل الشعب: الإجمالي، النسب، وجدول شامل بكل الإجازات.

## التشغيل محليًا

افتح ملف `index.html` مباشرة بأي متصفح حديث (Chrome / Edge / Safari). لا حاجة لأي تثبيت.

بيانات الدخول الافتراضية:

- اسم المستخدم: `admin`
- كلمة المرور: `12345`

يمكن تغيير كلمة المرور من داخل النظام بعد تسجيل الدخول (زر "تغيير كلمة المرور" أعلى الصفحة).

## ⚠️ ملاحظة أمنية مهمة

هذا تطبيق ثابت (Static) يعمل بالكامل داخل المتصفح دون خادم خلفي، لذلك:

- بيانات الإجازات وكلمة المرور تُحفظ في **ذاكرة المتصفح المحلية (localStorage) على نفس الجهاز**، ولا تُشارك تلقائيًا بين أجهزة أو مستخدمين مختلفين.
- تسجيل الدخول هنا هو حماية بسيطة (Client-side) لمنع الدخول العرضي، وليس حماية أمنية حقيقية بمستوى احترافي — أي شخص يملك حق الوصول لكود الصفحة يمكنه نظريًا تجاوزها. لا يُنصح باستخدامه لبيانات حسّاسة جدًا على الإنترنت العام دون إضافة خادم فعلي (Backend) لاحقًا.
- عند النشر على GitHub Pages فإن الموقع يكون **علنيًا** ما لم يكن المستودع خاصًا (Private) ضمن خطة GitHub تدعم صفحات خاصة، أو تقييد الوصول بطريقة أخرى.

## النشر على GitHub Pages

### الطريقة الأولى: عبر متصفح الويب (الأسهل، بدون أوامر)

1. أنشئ حسابًا على [github.com](https://github.com) إن لم يكن لديك حساب.
2. اضغط **New repository**، واختر اسمًا (مثلاً `leave-system`)، واتركه Public، ثم **Create repository**.
3. في صفحة المستودع الفارغ اضغط **uploading an existing file**.
4. اسحب ملف `index.html` (و`README.md` إن رغبت) وأفلته، ثم اضغط **Commit changes**.
5. اذهب إلى **Settings → Pages**.
6. تحت **Build and deployment** اختر **Deploy from a branch**، ثم الفرع `main` والمجلد `/ (root)`، ثم **Save**.
7. بعد دقيقة أو دقيقتين سيظهر رابط الموقع أعلى الصفحة بالشكل:
   `https://<username>.github.io/<repo-name>/`

### الطريقة الثانية: عبر سطر الأوامر (Git)

```bash
cd repo   # المجلد الذي يحتوي على index.html
git init
git add index.html README.md
git commit -m "Initial commit: leave management system"
git branch -M main
git remote add origin https://github.com/<username>/<repo-name>.git
git push -u origin main
```

ثم فعّل GitHub Pages بنفس خطوات الطريقة الأولى (الخطوة 5 وما بعدها).
