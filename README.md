# نظام إجازات المنسوبين

**المملكة العربية السعودية — وزارة الداخلية — المديرية العامة للدفاع المدني**
**إدارة الدفاع المدني بمنطقة المدينة المنورة**

تطبيق ويب من صفحة واحدة (Single-file HTML App) لإدارة إجازات منسوبي مركز تدريب الدفاع المدني بمنطقة المدينة المنورة — لا يحتاج إلى خادم أو قاعدة بيانات، ويعمل بالكامل من داخل المتصفح.

## المزايا

- تسجيل دخول باسم مستخدم وكلمة مرور، مع نظام صلاحيات بمستويين: **مدير** (صلاحية كاملة) و**مستخدم عرض فقط** (فحص البيانات دون تعديل).
- المدير يستطيع إضافة مستخدمين جدد وتحديد صلاحياتهم من داخل النظام مباشرة (زر "إدارة المستخدمين").
- أيقونات لكل شعبة/قسم: شعبة التعليم، شعبة التدريب، شعبة المساندة الإدارية، شعبة أجنحة التدريب، قسم الجودة التعليمية، المكتب.
- داخل كل شعبة (للمدير فقط): اختيار المنسوب ← اختيار نوع الإجازة (عرضية 1-10 أيام / اعتيادية 1-45 يوم) ← تاريخ البدء من تقويم ← حساب تاريخ الانتهاء تلقائيًا ← حفظ.
- **تصنيف تلقائي لحالة كل إجازة**: "قادمة" (لم يحن موعدها بعد) / "إجازة" (جارية الآن) / "منتهية" (انتهت) — ولا يدخل في نسبة "المتمتعين بالإجازة" إلا من كانت حالته "إجازة" فعليًا اليوم.
- نسبة المتمتعين بالإجازة ونسبة المتواجدين تُحسب لحظيًا بحسب تاريخ اليوم.
- **رسم بياني أسبوعي** (من الأحد إلى السبت) يوضح نسبة وعدد المتمتعين بالإجازة يوميًا، لكل شعبة وللمجموع العام، ويتحدّث تلقائيًا مع أي تغيير في البيانات أو التاريخ.
- جدول الإجازات السابقة لكل شعبة مع تصفية حسب المنسوب ونوع الإجازة، وإمكانية الحذف (للمدير فقط).
- صفحة "الإجازات العامة" تجمع كل الشعب: الإجمالي، النسب، الرسم البياني الأسبوعي، وجدول شامل بكل الإجازات.

## التشغيل محليًا

افتح ملف `index.html` مباشرة بأي متصفح حديث (Chrome / Edge / Safari). لا حاجة لأي تثبيت.

بيانات الدخول الافتراضية (حساب المدير):

- اسم المستخدم: `admin`
- كلمة المرور: `CD-Madinah@2026`

**يُنصح بشدة بتغيير كلمة المرور فور أول تسجيل دخول** (زر "تغيير كلمة المرور" أعلى الصفحة)، لأن هذه القيمة الافتراضية موجودة في كود الصفحة ويعرفها أي شخص يفتح الملف.

### نسيت اسم المستخدم أو كلمة المرور؟

بما أن التطبيق لا يتصل بخادم مركزي، لا يمكن استرجاع كلمة مرور منسية تلقائيًا. اضغط رابط "نسيت اسم المستخدم أو كلمة المرور؟" أسفل زر تسجيل الدخول لإعادة ضبط النظام على حساب المدير الافتراضي أعلاه. **تنبيه**: هذا الإجراء يحذف كل المستخدمين المضافين وكل سجلات الإجازات المخزّنة في **هذا المتصفح/الجهاز فقط**، ولا يؤثر على أي جهاز آخر يشغّل نفس الملف.

### إدارة المستخدمين

من حساب المدير، زر "إدارة المستخدمين" أعلى الصفحة يفتح نافذة لإضافة مستخدمين جدد بصلاحية "عرض فقط" (يفحصون الشعب والإحصائيات والجداول دون إضافة أو حذف) أو بصلاحية "مدير" كاملة، وحذف أي مستخدم عدا نفسك أو آخر حساب مدير في النظام.

## ⚠️ ملاحظة أمنية مهمة

هذا تطبيق ثابت (Static) يعمل بالكامل داخل المتصفح دون خادم خلفي، لذلك:

- بيانات المستخدمين وكلمات المرور وسجلات الإجازات تُحفظ في **ذاكرة المتصفح المحلية (localStorage) على نفس الجهاز**، ولا تُشارك تلقائيًا بين أجهزة أو متصفحات مختلفة. إذا فتح شخصان الرابط من جهازين مختلفين فلن يريا نفس البيانات.
- تسجيل الدخول هنا هو حماية بسيطة (Client-side) لمنع الدخول العرضي، وليس حماية أمنية حقيقية بمستوى احترافي — أي شخص يملك معرفة تقنية بسيطة يمكنه نظريًا تجاوزها من أدوات المطوّر في المتصفح. لا يُنصح باستخدامه لبيانات حسّاسة جدًا على الإنترنت العام دون إضافة خادم فعلي (Backend) وقاعدة بيانات حقيقية لاحقًا.
- عند النشر على GitHub Pages فإن الموقع يكون **علنيًا** ما لم يكن المستودع خاصًا (Private) ضمن خطة GitHub تدعم صفحات خاصة، أو تقييد الوصول بطريقة أخرى.

## النشر على GitHub Pages

### الطريقة الأولى: عبر متصفح الويب (الأسهل، بدون أوامر)

1. أنشئ حسابًا على [github.com](https://github.com) إن لم يكن لديك حساب.
2. اضغط **New repository**، واختر اسمًا (مثلاً `leave-system`)، واتركه Public، ثم **Create repository**.
3. في صفحة المستودع الفارغ اضغط **uploading an existing file**.
4. اسحب ملف `index.html` (و`README.md` إن رغبت) وأفلته، ثم اضغط **Commit changes**.
5. اذهب إلى **Settings → Pages**.
6. تحت **Build and deployment** اختر **Deploy from a branch**، ثم الفرع `main` والمجلد `/ (root)`، ثم **Save**.
7. بعد دقيقة أو دقيقتين سيظهر رابط الموقع أعلى الصفحة بالشكل:
   `https://<username>.github.io/<repo-name>/`

### الطريقة الثانية: عبر سطر الأوامر (Git)

```bash
cd repo   # المجلد الذي يحتوي على index.html
git init
git add index.html README.md
git commit -m "Initial commit: leave management system"
git branch -M main
git remote add origin https://github.com/<username>/<repo-name>.git
git push -u origin main
```

ثم فعّل GitHub Pages بنفس خطوات الطريقة الأولى (الخطوة 5 وما بعدها).

> ملاحظة: نسخة هذا المجلد تحتوي بالفعل على مستودع Git مهيأ محليًا بأول Commit على فرع `main` — إن كنت تستخدمها كما هي يكفي تنفيذ آخر سطرين (`git remote add` ثم `git push`) بعد إنشاء مستودع فارغ على GitHub.
